WebGL shader backdrop island

This page demonstrates the islands pattern: the static page opts in with two lines — a mount div and one <script type="module"> — and the self-contained bundle in /islands/ does the rest. No framework on the page, no build step for the site.

Runtime API: window.MeristemIslands.tuneShaderBackdrop(el, opts), replayShaderBackdrop(el), holdShaderBackdrop(el, 'chaos'|'calm').

Rebuild after changing island source: cd islands-src && npm install && npm run build
